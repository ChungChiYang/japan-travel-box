FUJIFILM X-T30 III Guide

日本旅拍參數與色彩指南

01 / 相機基礎參數說明

光圈 (F值)

控制進光與背景虛化。數字小（如 F1.8）背景糊；數字大（如 F8）風景前後都清晰。

快門速度 (S)

防手震與捕捉瞬間。街拍建議 1/125s 以上，運動人群 1/500s，手持極限 1/30s。

感光度 (ISO)

控制對光的敏感度。白天用 Auto1 (160-800)，暗光用 Auto3 (最高 6400)。

快門類型 (MS/ES)

MS 機械快門防果凍效應；ES 電子快門最高達 1/32000s，大晴天開大光圈必備。

對焦模式 (Focus Mode Switch)

S (單次)：半按快門對焦一次鎖定，適合風景、靜物與靜止人像。
C (連續)：半按快門持續追焦，適合走動人物、寵物與車輛。
M (手動)：轉動鏡頭對焦環手動對焦，適合夜景星空或隔著欄網防誤焦。

02 / 富士獨門色彩與明暗參數
富士系統白平衡設定 (WB Shift)
  • R (色調, 紅/綠)：增加偏紅暖調，減少偏綠涼感。
  • B (色溫, 藍/黃)：增加偏藍冷調，減少偏黃暖感。
  • 範例 (暖中帶綠)：R -1 / B -1（微減紅微減藍，增添些許日系青綠氛圍）。
  • 範例 (清新透亮)：R -1 / B +3（偏藍偏綠，打造乾淨日系透明感）。
  • 範例 (復古暖陽)：R +4 / B -5（偏紅偏黃，夕陽或溫暖濃郁底片感）。
富士系統 3 大飽和度設定
  • 色彩 (Color)：控制畫面整體飽和度。
  • 彩色效果 (Color Chrome Effect)：控制暖色（如人的膚色、暖色調建築、稻穗、紅葉等）飽和度與層次，一般環境設 Weak 即可。
  • 色彩漸變特效藍色 (Color Chrome FX Blue)：控制冷色（藍色調飽和度提升），適合大晴天天空或藍海。
富士系統 3 大對比度設定 (解決亮過曝、暗太暗)
  • 動態範圍 (Dynamic Range, DR)：數字小 (DR100) 中間調細節保留少、對比強；數字大 (DR200/DR400) 中間調細節保留多、對比弱（防亮部過曝）。
  • D範圍優先 (DR Priority)：同時自動調整亮部與暗部的無腦平衡模式（啟用時無法單獨調色調曲線）。
  • 色調曲線 (Tone Curve)：個別調整亮部 (Highlight) 與暗部 (Shadow)。常見 S 曲線（亮部拉亮 +1、暗部拉暗 +1）可讓畫面對比度變強、風格更濃烈。
