FUJIFILM X-T30 III Guide

日本旅拍參數與色彩指南

01 / 相機基礎參數說明

光圈 (Aperture, F值)

控制進光量與背景虛化。數字小（如 F1.8）進光多、背景虛化；數字大（如 F8）進光少、前後景象皆清晰。

快門速度 (Shutter, S)

控制進光時間與動態捕捉。街拍建議 1/125s 以上，運動人群 1/500s，手持極限 1/30s。

感光度 (ISO)

感光元件對光的敏感度。白天用 Auto1 (160-800)，暗光用 Auto3 (最高 6400)。越高噪點越多。

EV 曝光補償 (Exposure Value)

相機明暗總開關。相機測光常被大面積白（雪景/白牆）或黑背景欺騙。「逢白加光 (+EV)、逢黑減光 (-EV)」，逆光人像補 +1.0 ~ +1.7 EV 防臉黑。

快門類型 (MS/ES)

MS 機械快門防果凍效應；ES 電子快門最高達 1/32000s，大晴天開大光圈必備。

對焦模式 (Focus Mode Switch)

S (單次)：半按快門對焦一次鎖定，適合風景、靜物與靜止人像。
C (連續)：半按快門持續追焦，適合走動人物、寵物與車輛。
M (手動)：轉動鏡頭對焦環手動對焦，適合夜景星空或隔著欄網防誤焦。

02 / 曝光三要素核心概念與關聯性舉例
💡 通俗比喻：接水裝滿桶（裝滿水 = 曝光正確）

把「曝光」想像成用水龍頭接滿一桶水：
• 光圈 = 水龍頭開口大小（開越大，水流越多）。
• 快門 = 水龍頭開啟時間（開越久，接水量越多）。
• ISO = 水桶本身的吸水放大器（水不夠時硬放大幅度，但會產生雜質噪點）。

🔄 實戰連動補償關係（翹翹板效應）

為了維持畫面「亮度不變」，當你改變其中一個參數時，必須調整另一個參數來抵銷：

情境 A：晴天想拍背景虛化人像
  1. 開大光圈 (F2.8)
    讓背景變糊 ➔ 進光量暴增（畫面太亮）
  2. 補償方案：將快門調快 (1/1000s)
    縮短進光時間。
情境 B：夜間街拍怕照片手震模糊
  1. 調快快門 (1/125s)
    凍結畫面 ➔ 進光時間太短（畫面太暗）
  2. 補償方案：開大光圈 (F2.0) 加上提高 ISO (3200)
    補足亮度。
情境 C：大晴天拍風景想要前後清晰
  1. 縮小光圈 (F8.0)
    讓前後景色清晰 ➔ 進光量變少
  2. 補償方案：ISO 保持 160，快門放慢至 1/250s
    日光充足下，稍微放慢快門即可補足亮度。
情境 D：室內捕捉走動中的人物
  1. 快門必須 1/250s、光圈開最大 (F2.8)
    防動態模糊並儘量進光
  2. 補償方案：拉高 ISO (1600 - 3200)
    光線仍不足時，唯有提高感光度。
03 / 富士獨門色彩與明暗參數
富士系統白平衡設定 (WB Shift) 四象限風格

座標軸：橫軸 R（右紅/左綠）與縱軸 B（上藍/下黃），微調格數即可改變整體氛圍：

第一象限（右上：偏藍 + 偏紅 ➔ 冷紫/冷粉） 風格： 高冷帶粉紫調，日系空氣感與透亮少女感。
適用： 提亮亞洲人膚色（顯白通透）、夢幻紫調夜景。
第二象限（左上：偏藍 + 偏綠 ➔ 冷青/綠） 風格： 電影感（Teal & Orange）、森林系冷綠、日系底片質感。
適用： 夏天清涼海邊、晴空、陰雨天與極簡建築。
第三象限（左下：偏黃/暖 + 偏綠 ➔ 暖綠/橄欖綠） 風格： 濃郁復古、自然大地色系、老底片色調。
適用： 復古街景、綠意盎然的森林與日光穿透樹葉。
第四象限（右下：偏黃/暖 + 偏紅 ➔ 暖橘/夕陽金黃） 風格： 溫暖、熱烈、濃郁的金黃與暖橘光影。
適用： 夕陽落日、溫馨室內燈光、美食特寫。
  • 常見組合 (日系清新)：R -1 / B +3（偏藍偏綠，打造乾淨透明感）。
  • 常見組合 (復古暖陽)：R +4 / B -5（偏紅偏黃，強化夕陽或溫暖濃郁底片感）。
富士系統 3 大飽和度設定
  • 色彩 (Color)：控制畫面整體飽和度。
  • 彩色效果 (Color Chrome Effect)：控制暖色（膚色、暖色建築、紅葉等）飽和度與層次，一般設 Weak 即可。
  • 色彩漸變特效藍色 (Color Chrome FX Blue)：控制藍色調飽和度提升，適合大晴天天空與海洋。
富士系統 3 大對比度設定 (解決亮過曝、暗太暗)
  • 動態範圍 (Dynamic Range, DR)：DR100 對比強；DR200/DR400 保留高光與暗部細節（防過曝）。
  • D範圍優先 (DR Priority)：自動平衡亮暗部的無腦模式（啟用時無法單獨調色調曲線）。
  • 色調曲線 (Tone Curve)：個別調整亮部 (Highlight) 與暗部 (Shadow)。S 曲線（Highlight +1, Shadow +1）可讓對比度更鮮明。

06 / 實戰常見場景問題與操作對策
📷 場景 1：大晴天拍人像，背景太亮過曝，人臉太暗？
操作調整：開大光圈 (F1.8-F2.8) ＋ EV 滾輪直接加到 +1.0 ~ +1.3。同時設定 DR400 或 DR200 鎖住背景天空高光不爆白。
📷 場景 2：室內餐廳拍攝美食，照片總是被黃光籠罩、食物看起來不新鮮？
操作調整：按 WB 鈕進入白平衡設定，將偏移座標往 B (藍色) +2 至 +4 偏移以抵銷黃光，色調曲線 Highlight -1, Shadow +1 讓光影更平緩。
📷 場景 3：夜間日本街道/居酒屋，照片模糊且對焦一直拉風琴？
操作調整：將光圈開到最大，快門速度強制鎖定在 1/60s 或 1/125s，ISO Auto 設定為 AUTO 3 (上限 6400)。若對焦困難，可開啟「AF輔助燈」或切換為單點對焦對準高對比邊緣。
📷 場景 4：晴天戶外使用大光圈拍攝時，畫面一片白且快門鍵按不下去？
操作調整：因為機械快門速度達到上限 (1/4000s) 導致過曝。請進入選單將快門類型改為 MS+ES (機械+電子快門)，快門可自動提升至 1/32000s。
